# 宝可梦图鉴

一本可以自己点亮的宝可梦图鉴，有 macOS 和 Windows 两个版本。普通和闪光各有一本，互不影响。

图鉴开着的时候，键盘、鼠标按键或滚轮都算活动，鼠标移动不算。每 10 秒里只要有过活动，就获得 10 个精灵球。到探索里选择地区再投球。集满 3 只同一颜色会自动进化；最终形态会升级并自动换成金币。金币用来买增益、升级，或解锁超级进化和特殊形态。

十个地区都可以打道馆。普通版通关后解锁更高一级的对战。十个地区的高级冠军都打完后，可以挑战小智。他的阵容每个自然日更换，当天打赢后，回到图鉴会落下花瓣，一直持续到这天结束。

## 下载

到 [Releases](https://github.com/hahadada0528/pokemon/releases) 下载对应压缩包：

| 系统 | 文件 |
| --- | --- |
| macOS | `宝可梦图鉴-mac.zip` |
| Windows | `宝可梦图鉴-win.zip` |

## macOS

解压后打开 `宝可梦图鉴.app`。

如果系统提示无法打开，在 Finder 里按住 Control 再点这个应用，选择「打开」。按键计数需要在「系统设置 → 隐私与安全性 → 输入监视」里允许它。球数不增加时，把这项关掉再打开一次。

进度写在：

```text
~/Library/Application Support/PokemonPokedex/progress.json
```

## Windows

解压后保留整个文件夹，双击里面的 `宝可梦图鉴.exe`。不要把 exe 单独挪走，它要读取旁边的 `pokedex` 和 `data`。本机需要已安装 Microsoft Edge。

关掉窗口以后，托盘图标还在，按键仍会计数。要退出时，在托盘图标上选择退出。

进度写在：

```text
%LOCALAPPDATA%\PokemonPokedex\progress.json
```

## 存档

商店里可以导出、导入。空存档不会覆盖一份已经有进度的存档。按键获得的精灵球跟这台电脑绑定，换电脑时用导出和导入。
